# 書き手の声を残す中国語推敲

中国語の下書きを、事実・適用範囲・書き手の語り口を保ちながら整える Skill です。短い投稿、エッセイ、口頭用の原稿、指定箇所の批評に使えます。

状態：**実験的な公開ソース版**。非公開版から機能を絞り、以下の範囲と検証上の制約で公開しています。

## まずは合成例を見る

この例は説明用に作ったもので、実在の業務記録を匿名化したものではありません。中国語の推敲を確認するため、原文のまま掲載します。

入力：

> 我今天试了一个提醒工具。只试了 3 次，其中 1 次提醒晚了 2 分钟。先继续试试。

許容される軽い修正の例：

> 今天试了个提醒工具，试了 3 次，其中 1 次晚了 2 分钟。先继续试试。

「3 回試し、1 回は 2 分遅れた」という事実を残します。「いつも時間どおり」「大幅に時間を節約できた」といった主張には変えません。[固定ケースと制約](../../../skills/wang-xiaobo-writing/examples/synthetic-cases.json)、[独自の推敲例](../../../skills/wang-xiaobo-writing/references/before-after.md)も参照できます。上の文章は説明用の作例で、モデル実行の検証結果ではありません。

**最短の入口：** Markdown を読める AI アシスタントに、`skills/wang-xiaobo-writing/` の [SKILL.md](../../../skills/wang-xiaobo-writing/SKILL.md) を先に読ませ、その後に下書きを渡してください。関連ファイルを含め、Skill の `skills/wang-xiaobo-writing/` フォルダー全体を保ちます。

## この公開版の範囲

- 事実と既存の表現を先に守り、必要な箇所を直す流れを残しています。
- 数値、条件、範囲、因果関係の強さを維持し、体験、会話、否定的な事実を創作しません。
- 投稿先に応じた指針、空疎な表現の確認、独自の合成教材を含みます。
- 冗談、大げさな結論、複数案を既定で足しません。正式な通知は正式な文体のまま扱えます。

`wang-xiaobo-writing` は互換性のために残した識別子です。元の非公開プロジェクトは王小波の『沉默的大多数』を研究していましたが、この版には書籍の例との対応表、章の内容への参照、そこから導いた技法要約を含めていません。非公開版の文体抽出機能全体を提供するものではなく、著者や権利者の公認でもありません。[許諾範囲](../../../skills/wang-xiaobo-writing/LICENSE-STATUS.md)と[出典の説明](../../../skills/wang-xiaobo-writing/THIRD_PARTY_NOTICES.md)を確認してください。
