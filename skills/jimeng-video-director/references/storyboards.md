# 分镜与独立参考图

## 按目的选择形式

| 目的 | 合适的交付 |
|---|---|
| 比较全片节奏、景别和美术 | 叙事镜头板；按真正镜头数量组织，允许不同段落时长。 |
| 控制一镜中的动作过程 | 同镜状态板或独立起／关键接触／落态图；明确它们不是切镜。 |
| 逐镜图生视频或首尾控制 | 独立干净参考图；每镜的上传图片与提示词一一对应。 |
| 锁身份、产品或环境 | 三视图／产品图／场景元素图，标明它们的参考职责。 |
| 控制机位与动作而美术未定 | 在当前入口支持下使用简洁预演、线稿或白模参考；不冒充已完成的摄影质感分镜。 |

按用户目标选择 9:16、16:9 或其他画幅，不固定每格 16:9。宫格数量由镜头或状态数量决定，不按总秒数机械套九宫格，也不把每秒状态都当成一次切镜。

如果一张板同时含独立镜头和同镜状态，逐格写清镜号、状态号和时间。多格控制视频不应带出格线、序号或多个重复人物。

## 制作前的参考核对

先找用户已选人物、服装、产品官方图和场景资产，实际查看后再生成。分别记录当前版本；不能仅凭文字重新造脸、改衣或改变包装。

缺少新的手位、持物、起落幅或同框关系时，列具体补图任务。既有图可以继续作身份／材质参考，但不能标成新镜头已经完成。

图片里的视觉细节要有可用依据，或被明确说明为本轮新增创作设计；产品标识、形态、尺度与功效事实不可凭空补全。

## 生图与合成

摄影质感分镜、人物和材质图使用图像生成工具或用户指定的生成流程。代码图形可以表示布局、机位、时间轴和灰模预演，但不能冒充已生成的写实分镜。

用户明确要求保留官方产品原图／选择等比合成时，使用原图层处理包材，保持宽高比例；手指遮挡、承重、接触阴影与光向须匹配。背景与人像需要生成型改动时仍走相应图像工具。

逐镜上传图清理掉镜号、时长标签和界面截图边框。审看板可以加必要编号，但和真正上传资产分开。保留原始生成图、采用图和来源记录。

## 输出检查

- 最终画幅用等比缩放与可审看的裁切取得，不用拉伸把产品压扁；改变裁切后再次核对重要部位和字标。
- 识别透明通道：需要完整场景时提供不透明成片参考；需要透明产品层时保留 alpha，不默认所有 PNG 都透明或都不透明。
- 检查脸、发型、衣物、耳饰、手指根部、接触点、罐体比例、标签、胶囊尺度、皮肤与纸标噪点。
- 分镜图、文字起态、落态和镜间接法一致，图片显示“已贴面”时不把它写成尚未靠近。
- 多角度图只表明设计约束，不能承诺生成视频里身份或字标已经锁定。

交付位置沿用项目已有目录；新版本清楚命名，不强制固定 `scene-01.png` 路径，不覆盖已批准或已提交的版本。
