# 回片、剪辑与返工

## 先区分三种时间

生成素材长度、已验证可用区间、成片采用区间分别记录。不能把两条各五秒的素材全长观看感受，直接等同于计划三秒开头的剪辑节奏。

有足够镜头时尽早试组一段，先看整体观看感受，再定位问题。不要为了整齐把每镜等量削短，也不要为生成成本已经发生而保留无叙事作用的镜头。

## 审查顺序

1. **观看结果**：这一镜完成了什么发现、使用动作、情绪或品牌信息；运动之后是否只是多出背景。
2. **身份与产品**：同一人物、衣着、持物、罐形与字标；好看的错包装不能通过。
3. **空间与动作**：方向、轴线、前后距离、接触、承重、遮挡、物体刚性和焦点；区分相机移动与景物自行漂移。
4. **图像质地**：皮肤、纸标、胶囊、玻璃是否有污点、重复网纹、过度磨皮或闪变；正常纸张纹理与生成噪点区分。
5. **剪辑接缝**：看前镜落态与后镜起态、相同动作是否重做、物体是否转手、视线是否接到正确目标。
6. **声音与文字**：意外自动配音、音乐、字幕；对白、环境、音效和配乐分别处理。素材没有音频分析时不判断节拍或声音质量。

尽可能按正常速度看实际片段，再针对可疑接触、形变或切点密集抽帧。只有联系表时，结论限于抽样画面；文件解码通过和截图可读不等于动态一致性通过。

## 给失败归因

| 现象 | 优先核对 | 可能的最小修正 |
|---|---|---|
| 整体像活动海报 | 起幅是否已经给完信息；场景是否缺可识别的前后层 | 改起落幅／空间主图，再写揭示动作。 |
| 产品越拉越小、背景抢戏 | 目标构图与真实落幅、托面与背景反光 | 选较早可用区间；有必要才重定尾幅。 |
| 人物僵硬 | 有无目标、刺激和反应；是否堆微表情 | 保留一条动机与少量可见反应。 |
| 手穿物或接触突变 | 起态、夹持、承重转移、指根和相邻手位 | 补关键接触状态，缩减动作链。 |
| 包装变形／字标漂移 | 参考来源、画面裁切、未知角度、形变时段 | 改输入、限制外推、局部修复或按已授权方式合成。 |
| 本体未动但扫光很热闹 | 是否用亮斑或布料运动代替所需机位变化 | 稳定环境，补轨迹参考或调整镜头任务。 |
| 两镜各自漂亮但接不上 | 方向、光、动作相位、景别与主次 | 改切点、选替代素材、明确省略，必要时补桥接。 |

以证据区分脚本问题、输入图问题、生成执行偏差和剪辑问题。多个因素同时改动时，只能记录改善，不能证明某一句提示词导致了效果。

## 返工单

对需要返工的段落记录：镜号和版本、源时间区间、可见问题、要完成的观看结果、起落态、保护内容、修改变量、参考文件和接受条件。新增付费操作遵循当前授权；修稿或建议本身不产生新提交许可。

优先顺序由缺口决定：已有可用片段可剪 → 有替代 take 则比较 → 局部问题考虑编辑 → 缺关键状态补图 → 轨迹不稳考虑白模 → 实在缺镜才生成。不是机械要求每次都走完全部阶段。

画面确认后再做整体声画收束。若后续重新改镜头长度或顺序，核对音乐、字幕与其他依赖，不把旧验收沿用到新版本。
