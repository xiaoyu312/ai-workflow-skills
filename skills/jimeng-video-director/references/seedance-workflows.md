# Seedance 工作流与执行

本文件是操作选择方法，不保存会过期的数量、秒数或分辨率硬上限。需要提交时核对当前模型、入口与子命令；只写创意或诊断镜头时不必为无关参数做全量联网调查。

## 操作与控制可以组合

| 操作 | 控制重点 |
|---|---|
| 新生成一个片段 | 确定单镜或多镜段，按真实素材选择文字、首帧、首尾或全能参考。 |
| 长故事或多场景段落 | 当前入口是否支持目标时长；幕／场景任务、角色状态和转场；时间戳是控制手段，不假定它就是独立平台模式。 |
| 延长已有视频 | 明确新增片段放在原片之前还是之后，只对新增时段写指令；对齐原片首帧或末帧状态。 |
| 局部编辑 | 指定对象、位置／标记、A→B 改动、生效时段、保护内容与遮挡补全。 |
| 两段之间补过渡 | 两端顺序、原片保持范围、桥接对象、方向、大小、速度和接入状态。 |
| 需要轨迹／站位控制 | 把白模或运动参考作为上述操作的控制来源；保真包装仍来自官方资产。 |
| 多宫格参考 | 每格是镜头还是同镜状态先说清；可与人物、产品、场景、长故事等兼容控制组合。 |

用户说“向前续写”但位置含糊时，根据明确的首／末帧或之前／之后描述判断；仍有实质歧义才问。不要让“继续”在已明确后续故事时机械触发重复确认。

## 白模与空间预演

粗白模主要提供路径、站位、相对尺度与遮挡；按颜色／位置／形状映射每个代理到人物、产品或道具，不继承灰材质、简化包材和视口叠层。不能仅有僵硬体块移动就声称已控制复杂肢体表演。

精细白模已有完整几何与动画，重点是渲染、材质、光和环境；注明保护的机位、时序与对象关系。需要未见包材视角时补可靠官方角度或核验三维结构，而不是把补出的背面当事实。

白模轨迹的验收对象是空间运动；最终视频还需核查身份、材料、字标与表演。清除坐标轴、轨迹线、网格和相机锥体。

## 当前规格怎么查

- 执行前查阅所在地区和操作入口的当前官方手册；本包不附手册快照或私有文档链接。
- 涉及真实执行时，记录核验日期、模型、操作入口、素材数与合计时长、输出规格和声音设置。无法查看某项就明确未核对，不能编新上限。
- CLI 工作流先读 `dreamina -h` 和对应子命令 `-h`，并使用当前可用的 `dreamina-cli` Skill。图生、首尾、多模态可能对画幅参数有不同规则，不复制另一命令的参数组合。

样片、低分辨率和正式生成是不同概念。入口没有可核实的样片模式时，不把某个低分辨率选项宣称为原生 Draft；用户选定规格后照已有选择执行。

## 执行与返还

已授权生成时，先锁实际输入文件及顺序、提交正文、模型和参数，再提交允许数量。不要在等待结果期间换掉输入快照。

返回任务 ID 只证明受理；保留 ID，继续查询相同任务直到成功、失败或具体阻塞。查询超时或本地下载失败，不自动新建付费任务。真实重试的范围和次数由当前用户授权决定。

下载后核对实际画幅、时长、音轨和文件可用性，保留原始回片。提示词写静音但回片有音轨时，交付独立静音副本并说明处理，不能只凭提示词宣称无声。

画面审查按 [回片与剪辑审查](editing-review.md)；平台成功、文件到位、视觉检查、采用和锁片分开记录。
