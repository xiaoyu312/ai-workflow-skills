# AI 動画制作のディレクション

AI 動画を制作する人向けに、脚本、ショット計画、参考素材の役割、連続性、プロンプト修正、生成された映像のレビューを整理するワークフローです。タイムライン、素材参照、宣言した状態を確認する Python 標準ライブラリ製の検査ツールも含みます。非公開の業務入力やメディアは含めません。

状態：**実験的な公開ソース版**。

## まずは計画の状態を見る

[合成ショット計画](examples/demo.json)では参考素材を意図的に `planned` としています。想定する確認結果は「構造は有効、素材は未準備、映像品質は未検証」です。計画が整っていても、素材や完成映像が存在することにはなりません。

**最短の入口：** フォルダー全体を保ち、Markdown を読めるアシスタントに [SKILL.md](SKILL.md) を読ませてから、この例や自分の許諾済み入力を渡します。

## 導入と使い方

利用環境が指定する Skill ディレクトリへ、`jimeng-video-director` という名前のままフォルダー全体をコピーします。あるいはタスクの前に `SKILL.md` を直接読むよう依頼してください。インストーラーはなく、利用環境固有の呼び出しやモデルの挙動は未検証です。

既存の呼び出し例：`Use $jimeng-video-director with the synthetic examples and clearly mark missing facts.`

操作指示、テンプレート、一部の例は主に中国語です。出力言語は依頼で指定できますが、日本語生成の品質は検証していません。

API キーや環境変数は不要で、使わない `.env.example` も同梱していません。実際のプラットフォーム操作には、利用環境側で既に許可された機能が必要です。このパッケージが有料ジョブの投入、素材のアップロード、元の業務記録の編集を自動で行うことはありません。

## 合成例と確認コマンド

例は固定シードから作り、「模拟数据 DEMO」と明示しています。実際の業務記録を匿名化したものではありません。Python 3 の標準ライブラリだけを使います。

```sh
python3 -B scripts/generate_demo.py
python3 -B -m unittest discover -s tests -p "test_*.py"
```

`python3 -B scripts/check_plan.py examples/demo.json` で合成計画を確認できます。参考ファイルは `planned` のままなので、構造の有効性と素材の準備状況を分けて読み取ってください。

検査対象はファイル構造、参照、例に明示された制約です。モデル品質、現在のプラットフォーム機能、業務効果、生成メディアを検証するものではありません。このパッケージはホスト型サービスではなく、今回の文書整理でもパッケージのテストや動画生成は実行していません。
