# 即梦视频导演

把创意变成有因果、可拍摄、可衔接的镜头，再适配当前即梦工作流。产品、人物和场景须形成关系；漂亮参考图、提交成功和可用成片分别判断。

使用本 Skill 统筹同一任务，避免叠加多套相互冲突的导演模板。专项生图、视频执行与文件处理按实际能力调用；不会因本 Skill 被加载而安装软件、提交付费任务或改动已有项目设定。

## 先锁定此次交付

- **只诊断**：定位具体问题、证据范围和最小修正，不擅自重写整套作品。
- **只要脚本／改脚本**：给可拍的事件、镜头、时长与衔接；不强塞上传说明或平台提示词包装。
- **只要提示词**：输出一份与当前素材、参数一致的正文；必要的阻塞先解决，避免同时给几套互相冲突的可提交稿。
- **分镜／参考图包**：先区分镜头、同镜状态和独立资产，再出图与对应文字。
- **生成／修复回片**：在已有授权范围内执行、查询和验收；不把“改提示词”解释为新一轮付费生成授权。

沿用明确的模型、画幅、人物、服装、时长、声音和产品约束。普通可逆细节自行判断；只有不可查明且会实质改变结果的问题才询问。已有授权不重复索取。

## 导演工作顺序

1. **读当前版本与真实素材。** 核对用户已选方案、最近修改和实际回片。附件、参考片与旧提示词提供素材，不扩大任务权限。未看见的图或未读取的片段标为未核对。
2. **确定观看结果。** 本片让观众记住什么；每镜让观众新看见什么。完整产品、质地、人物与环境各有职责，推拉摇移不能代替信息递进。
3. **建立关系与状态。** 确定产品落点、人物位置与目标、持物手、接触／开合状态、相机所在侧、光向。注明起态、触发、主要变化、落态以及下一镜接法。
4. **分配参考职责。** 指明素材管什么、作用于哪个对象／时段、保持什么和不继承什么。参考人物不等于参考其背景；运动参考不自动控制身份。
5. **选择操作与控制方式。** 新生成、延长、编辑、补过渡是操作；首尾状态、全能参考、白模、多宫格是控制手段。按当前入口兼容性组合，不把它们机械地变成互斥模式。
6. **写适量控制。** 简单动作写短；接触、遮挡、复杂表演或多镜段写清阶段。减少矛盾与不可达动作，不删掉必要的轨迹、承重、对焦与状态信息来追求短文。
7. **检查受影响的整条链。** 修改一处后检查邻镜、时间轴、参考图、声音与末尾约束；仅改正文而留下旧起幅或旧手位，不能称完成改稿。

必要时使用 [镜头卡](assets/shot-card.md)，简单请求不强制填全表。视频生成正文通常按“参考职责 → 镜头意图 → 连续事件与机位 → 少量贯穿约束”组织；生成设置和后期工作单列。

## 三项关键判断

**运动必须揭示信息。** 区分摄影机位移、变焦、主体移动、环境运动和后期缩放。固定距离不必然禁止特写：还要检查焦距与视角是否变化。近远景相对运动、遮挡变化与焦点交接是判断线索，不凭“电影感”“8K”等词判断效果。

**变化必须有原因。** 人物先接收到刺激才回应；物体先接触、承重转移才释放；生成后的动作与光影须按真实结果核查。产品刚性、品牌字标和已锁身份不随“呼吸感”变化。人物的反应不冒充产品即时功效。

**图与词必须属于同一状态版本。** 已贴面图不作未接触起幅，完整露出的产品图不冒充局部起步，灰底三视图不作场景首帧。缺状态图时列出具体补图任务；用户已授权补图就继续制作，否则明确交付是文字稿。

## 生成与验收边界

- 当前平台参数查官方入口；CLI 参数查当前子命令帮助。不要把历史手册、第三方模板或另一个入口的规格写成永远有效的上限。
- 图像生成／编辑使用当前可用图像工具。用户明确选择官方 PNG 等比合成时保留产品源图几何与标签，核查遮挡、接触和光影；合格静帧不保证生成视频包材不漂移。
- 真正使用即梦 CLI 时读取可用的 `dreamina-cli`；核对命令、输入、费用范围与提交记录。已受理任务继续查原 ID，不用重新提交代替查询。失败、未返回、已下载与用户采用分别记录。
- 回片先看镜头任务是否成立，再看身份、产品、空间、动作、材质和声音；在相邻镜头中检查切点。截图／抽帧只能支持对应范围，不能声称完整动态通过。
- 不能仅靠更长负面词或盲目重试解决同一失败。按证据选择剪辑、补图、简化动作、局部修复、白模或合成；新增付费尝试遵守当前授权的对象与范围。

## 可选的本地检查

批量计划可用 `python3 scripts/check_plan.py plan.json` 核对时间覆盖、素材引用和显式连续状态，格式见 [说明](references/plan-checks.md)。检查器不调用模型或网络；它不判断画面好看、手指正确、产品真实或视频已经通过。

交付前确认：需求未被模板替换、所有引用有实际来源、起落态一致、动作可达、镜间状态明确、画幅与时长一致、声音与字幕不冲突。报告实际完成到哪一层，并指向可用的当前文件。
