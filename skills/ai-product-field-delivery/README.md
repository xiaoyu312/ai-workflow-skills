# AI 产品现场交付

[FateClear：免费的生日排盘与解读网站](https://fateclear.com) · [在 X 关注作者项目与更新](https://x.com/liu_xiaoyu27334)

把 AI 工具、检索、Agent 或自动化需求整理成可以讨论和验收的交付文档。公开版提供四个入口：交付简报、评测方案、发布计划和运行复盘。

它适合需要回答“做哪一段、怎样验证、出错谁接手”的开发者、产品经理和交付负责人。普通个人工具可以只使用相关模板，无需走完整咨询流程。

## 先看交付示例

[合成练习](examples/synthetic-request.md)讨论只读 CSV 的库存问答助手，没有真实问答日志。交付应是评测计划与待补证据，而非“已节省 50% 时间”；即便合成题全答对，也不自动获得写库存或部署权限。

**最短入口：**让能读取 Markdown 的助手先读本目录的 [SKILL.md](SKILL.md)，再提交案例或自己的授权输入。完整目录与安装条件见下文。

本页提供三语介绍；操作指令、模板和部分示例仍以中文为主。可在请求中指定输出语言，但未验证跨宿主调用或日文生成效果。

## 使用

将本目录完整放入你的 AI 助手支持的本地 Skills 目录；确认宿主能够读取 `SKILL.md` 及相对路径资源。具体安装位置取决于宿主。此包不需要安装依赖、API 密钥或网络服务。

示例请求：

> 使用 ai-product-field-delivery，为一个只能读取 CSV 的库存问答助手设计评测方案。当前没有真实查询日志，不要部署，也不要假设已经节省成本。

入口文件是 [SKILL.md](SKILL.md)。它会按当前任务选择四份模板之一；[合成练习](examples/synthetic-request.md) 可用于检查输出是否分清方案、证据和已执行结果。

## 范围与限制

- 保留现场交付的目标用途：明确范围与基线、设计验收、安排人工接手和失败处理、复盘实际效果。
- 本次公开版重新编制了通用入口和空白模板，未直接沿用私有版的章节映射、参考文件或八阶段组织方式。
- 未包含书稿、章节摘要、第三方案例、客户材料、日志、秘密值或原项目运行记录。
- 不承诺复现私有版或任何来源作者的完整方法体系和效果。模板检查与合成场景检查不等于真实交付验证。
- 技术、业务和专业判断仍需依赖当前项目证据及相应负责人。
