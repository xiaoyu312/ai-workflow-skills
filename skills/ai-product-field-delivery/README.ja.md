# AI プロダクトの現場導入計画

AI ツール、検索、Agent、自動化の依頼を、人がレビューし検証できる納品文書にまとめます。公開版には、導入ブリーフ、評価計画、リリース計画、運用レビューの四つの入口があります。

範囲、検証方法、人への引き継ぎを明確にしたい開発者、プロダクトマネージャー、導入責任者向けです。小さな個人用ツールでは、必要なテンプレートだけを使えます。

## まずは評価計画の例を見る

[合成課題](examples/synthetic-request.md)は CSV の読み取りだけを許可された在庫問い合わせアシスタントで、実際の質問ログはありません。提出するのは評価計画と不足する証拠です。「時間を 50% 削減した」とは言えません。合成問題に全問正解しても、在庫の更新やデプロイの許可が自動で得られるわけではありません。

**最短の入口：** アシスタントに [SKILL.md](SKILL.md) を読ませ、この課題から評価計画を作るよう依頼します。計画、証拠、実際に行った操作を区別できているか確認してください。

## 導入と使い方

アシスタントが対応するローカルの Skills 配置先にフォルダー全体をコピーします。利用環境は `SKILL.md` と相対参照先を読める必要があり、配置場所は利用環境に依存します。このパッケージに追加依存関係、API キー、ネットワークサービスは不要です。

依頼例：

> ai-product-field-delivery を使い、CSV を読むだけの在庫問い合わせアシスタントの評価を設計してください。実際の質問ログはありません。何もデプロイせず、コスト削減がすでに実現したとは仮定しないでください。

`SKILL.md` から目的に合うテンプレートへ進みます。指示とテンプレートは中国語です。利用者の希望する出力言語を依頼できますが、日本語生成の品質と利用環境ごとの導入は未検証です。日本語の README は手順自体の翻訳版ではありません。

## 範囲と制約

- 範囲と基準値の明確化、受け入れ条件の計画、人への引き継ぎと失敗時の対応、観測結果のレビューを扱います。
- 新しく用意した汎用の指示と空欄フォームを使い、非公開版の章対応表、参考ファイル、八段階の構成をそのまま再利用していません。
- 書籍本文、章の要約、第三者の事例、顧客資料、ログ、秘密情報、元の実行履歴は含みません。
- 非公開版や出典著者の方法・成果の完全再現を主張しません。パッケージ検査や合成課題は、実際の現場導入の検証ではありません。
- 技術、事業、専門上の判断には、当該プロジェクトの証拠と責任者の判断が必要です。

今回の文書整理ではモデル、導入先のシステム、実業務での効果を検証していません。
