# 爆款结构拆解与 目标品牌 迁移工作流

## 目录

1. 输入门槛
2. 拆解爆款
3. 判断什么能迁移

5. 重建脚本

## 1．输入门槛

优先接收本地视频文件或用户直接附加的视频。若输入是链接：

- 只使用当前会话可调用的浏览器、下载或授权能力；
- 不绕过登录、风控、版权或访问限制；
- 无法取得视频本体时，只基于用户提供的文字、截图和可见信息工作，并明确证据不足；
- 不把页面标题或文件名写成已经看过的真实画面。

先确认投放目标是 `推直播` 还是 `推商品`。未指定时，结合 CTA 判断并标为假设。

## 2．拆解爆款

使用当前已授权能力检查用户提供的素材，人工复核关键帧；本包不包含媒体处理程序。至少形成以下卡片：

### 基础信息

- 时长、画幅、镜头切换数量和首 3 秒切换数量。
- 人物、场景、道具、产品露出、字幕、音效和剪辑形式。

### 0—3 秒钩子

分别写清：

- `视觉钩子`：第一眼看到的人、动作、冲突、结果、数量或反差。
- `口播钩子`：首句对谁说、提出什么问题或冲突。
- `屏幕字`：是否补足对象、结果、价格或悬念。
- `筛选作用`：吸引的是哪类人，是否与后续成交人群一致。

### 中段种草

按实际出现顺序标记：

1. 痛点／处境。
2. 产品介入。
3. 一个核心卖点。
4. 可视化证明。
5. 主要异议处理。
6. 价格、规格或活动机制。

不要强行把每条视频都填满六项；缺失项如实标注。

### 结尾引导

- 行动对象：进直播间、点商品、领券、选择规格或下单。
- 行动理由：前文已经证明的产品价值或真实机制。
- 紧迫性来源：必须真实；无证据时删除。

### 节奏

- 每段时间占比。
- 前 3 秒、前 10 秒镜头数量。
- 人物、产品、证明、机制分别何时第一次出现。
- 哪一段承担停留、CTR、CVR，不用“好看”“高级”代替功能。

## 3．判断什么能迁移

把爆款元素分成四层：

| 层级 | 示例 | 处理 |
|---|---|---|
| 功能结构 | 价格冲突开头、痛点后马上演示、结尾点商品 | 可以迁移 |
| 表达机制 | 反问、劝退、人群点名、数量视觉化 | 可重写后迁移 |
| 品牌事实 | 竞品成分、检测、价格、赠品、用户评价 | 必须替换 |
| 受版权保护的具体表达 | 逐句文案、独特剧情、人物素材、音乐、原画面 | 不复制 |

先写“结构保留／目标品牌 替换矩阵”，再写成稿。每项必须回答：

- 原素材这一段解决什么漏斗问题？
- 目标品牌 用哪个真实痛点、卖点、证据和镜头完成同一功能？
- 若无法完成，是否应删除这一段，而不是硬套？

## 4．选择 目标品牌 商品与主问题

读取用户本次提供且有权使用的事实说明。按任务选择：

- 一个商品或商品组合；
- 一个优先人群；
- 一个具体处境；
- 一个核心卖点；
- 一个可拍证据；
- 一个真实行动。

若价格、赠品、活动或功效数字未在当前任务确认，保留 `[待确认]`，脚本状态只能是“补信息后可拍”。

## 5．重建脚本

遵守以下顺序：

1. 先复刻爆款的结构功能和时间比例。
2. 把竞品事实全部清空。
3. 用 目标品牌 人群处境重写首句，确保钩子与后续卖点一致。
4. 在中段只推进一个核心卖点；产品事实、使用变化和用户意义连续表达。
5. 用真实动作、道具、同条件对比、检测信息或规格数量把卖点可视化。
6. 只处理一个主要顾虑。
7. 根据推直播／推商品重写 CTA。
8. 按真实口播速度朗读，缩减到目标时长。

不要把爆款每一段机械一一替换。若原素材依赖竞品独有资产、名人或虚假机制，保留漏斗目的，重新设计表达。

## 6．匹配参考

只用用户合法提供的参考，按停留、解释、证明或行动等功能选择。可借鉴景别、机位、动作和信息组织，不复制外部品牌画面。

## 7．参考交付

记录实际参考的文件、时间点、使用权限、借鉴职责与本次替换要求。缺图时写待补及拍摄说明，不能声称附带素材。

## 8．质量门槛

交付前逐项检查：

- 原爆款的结构功能已提取，竞品事实与 目标品牌 事实已分离。
- 前 3 秒吸引的人群与后续成交人群一致。
- 目标品牌 只有一个核心卖点，且有可拍证据。
- 口播、屏幕字、画面和 CTA 表达同一件事。
- 价格、赠品、活动、数字、功效和背书均有当前来源。
- 推直播与直播间承接一致；推商品在视频内完成购买解释。
- 图片参考来自 目标品牌 原片或本次拍摄草图，不把竞品画面作为可直接复用资产。
- 口播能在目标时长读完，每个镜头有演员、场地、道具和动作。
- 结果标记为 `可拍`、`补信息后可拍`、`需重做指定段` 或 `不建议执行`。
