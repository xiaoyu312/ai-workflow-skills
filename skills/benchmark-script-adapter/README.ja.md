# 参考動画の構成を独自脚本に活かす

参考動画の役割や構成を分析し、利用を許可された商品情報から、独自の撮影用脚本を組み立てるコンテンツ企画者向けワークフローです。非公開の業務入力やメディアは含みません。

状態：**実験的な公開ソース版**。

## まずは合成入力と構成を見る

[収納ボックスの合成例](examples/demo.json)にある商品事実は「折りたたみ式」「ふた付き」です。「問題提示→実演→行動を促す」という機能的な構成を使いますが、価格、耐荷重、キャンペーン条件は未確認です。結果の状態は `补信息后可拍`（不足情報を補えば撮影可能）のままです。事実が足りないのに、完成した撮影台本だとは扱いません。

**最短の入口：** フォルダー全体を保ち、アシスタントに [SKILL.md](SKILL.md) を先に読ませてから、例や許諾済みの参考入力を渡してください。

## 導入と使い方

利用環境が指定する Skill ディレクトリへ、`benchmark-script-adapter` の名前でフォルダー全体をコピーします。`SKILL.md` を直接読むよう依頼することもできます。インストーラーはなく、利用環境固有の呼び出しやモデルの挙動は未検証です。

既存の呼び出し例：`Use $benchmark-script-adapter with the synthetic examples and clearly mark missing facts.`

指示、テンプレート、一部の例は主に中国語です。出力言語は指定できますが、日本語生成の品質は未検証です。

API キーや環境変数は不要で、使わない `.env.example` は同梱していません。実際のプラットフォーム操作には利用環境側の許可済み機能が必要です。有料ジョブの投入、素材のアップロード、元の業務記録の変更は自動で行いません。

## 提供範囲と制約

特定ブランドの商品知識、過去の動画分析、映像、参考フレーム、ダウンロード・文字起こしツール、抽出スクリプトは除外しています。利用者が許諾済み入力を用意してください。合成例も価格や性能の根拠を意図的に欠いており、追加情報が必要な状態を示します。

## 合成例と確認コマンド

例は固定シードで作成し、「模拟数据 DEMO」と明示しています。匿名化した業務記録ではありません。Python 3 標準ライブラリのみを使います。

```sh
python3 -B scripts/generate_demo.py
python3 -B -m unittest discover -s tests -p "test_*.py"
```

検査はファイル構造、参照、例で宣言した制約を確認します。モデル品質、現在のプラットフォーム機能、業務効果、生成メディアは検証しません。ホスト型サービスではありません。今回の文書整理でもテストや素材取得を実行していません。
