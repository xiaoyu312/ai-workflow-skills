# EC 広告の週次レビュー

EC 広告の担当者が、データの版と比較期間をそろえ、指標を再計算し、観測事実と仮説を分け、元に戻せる改善策をまとめるワークフローです。非公開の業務入力やメディアは含みません。

状態：**実験的な公開ソース版**。

## まずは合成レポートを見る

[合成データ](examples/demo.json)の当期広告費は 1500、GMV は 4500 で、再計算した ROI は 3 です。二つの区分の金額を全体と照合します。担当者の操作メモは仮説にとどめ、数値変化の原因とは断定しません。この例は計算と証拠の扱いを示すもので、実際の業績ではありません。

**最短の入口：** Markdown を読めるアシスタントに [SKILL.md](SKILL.md) を読ませ、合成例か利用を許可された自分の入力を渡してください。

## 導入と使い方

利用環境が指定する Skill ディレクトリに、`tmall-wanxiang-weekly-review` の名前でフォルダー全体をコピーします。タスクの前に `SKILL.md` を直接読ませる方法でも使えます。インストーラーはなく、利用環境固有の呼び出しやモデルの挙動は未検証です。

既存の呼び出し例：`Use $tmall-wanxiang-weekly-review with the synthetic examples and clearly mark missing facts.`

指示、テンプレート、一部の例は主に中国語です。希望する出力言語を指定できますが、日本語生成の品質は未検証です。

API キーや環境変数は不要で、使わない `.env.example` は同梱していません。実際のプラットフォーム操作には利用環境側の許可済み機能が必要です。有料ジョブの投入、アップロード、元の業務記録の編集は自動で行いません。

含まれるのはレビューの方法とレポート仕様です。元の非公開レポート生成器やデータコネクターは含みません。合成例は計算と区分別の照合を扱い、本番レポート全体の写しではありません。アシスタントが許諾済み入力に手順を適用するか、別途レビューした生成器が仕様を利用する想定です。旧識別子は公式サービスや公式版を示すものではありません。
