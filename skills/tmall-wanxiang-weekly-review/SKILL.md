# 天猫万相台周复盘

每周同一套方法。先由用户指定合法数据来源、本周区间和权威版本；再明确口径、证据分层和交付范围。

## 每周输入

只要这些，缺了再问，不要猜：

- 飞书工作簿 URL（wiki / sheets 均可）
- 本周子表：用 `sheet=` 或子表名；**期间以单元格为准，不以标签名为准**
- 对照周、正常基线周、月进度表：默认取相邻两周 + 本月进度；用户另指定则覆盖
- 运营备注：可选。全部先标 `待验证`，能被单元格证伪或证实后再改层

不要向用户要 token、内部 ID、MCP 地址。交付物里也不许出现这些。

## 工作流

1. 读飞书在线单元格，锁定 revision。本地 XLSX 只做完整性检查；网格为空或冲突时，以在线单元格为准。
2. 探查只看样貌：表名、期间单元格、字段、前几行、`#REF!` / `#DIV/0!` / 空行。禁止把整表打进上下文。
3. 写入 `evidence/source_snapshot.json`。字段见 [caliber.md](caliber.md)。
4. 复算并对账。断言失败就停，不编数补画面。
5. 先写判断，再写原因分层，再写可回滚动作。
6. 根据已核对快照生成报告；若使用用户另外提供的报告生成器，先审查其来源与读写范围，不手改产物中的数字。
7. 如当前环境允许界面验收，检查首屏、交互与窄屏；否则明确未完成界面验证。保存到用户指定的交付目录。

本公开包不附原项目报告生成器。可按本契约交付 Markdown／HTML；任何外部生成器须由用户另行提供并单独审查。

读表只用宿主环境已授权能力；本包不提供连接器，也不修改源表。

## 必须先锁的口径

- 同一账号、同一店铺范围、同一时间窗、同一指标定义。运营 GMV 和推广 GMV 不能直接相加。
- 先看单元格期间，再看子表标签；两者冲突时记录质量问题，以已确认的权威期间为准。
- 环比对照周若含大促无效展现，漏斗（展现 / CPC / CVR / 点击）会“全好了”。**必须再对照最近一个正常周**，不能只报环比。
- `缺失`、空白模板、`不适用`、`#REF!`、`#DIV/0!` 和真实 `0` 必须分开写。分母为 0 写成不适用，不写成 0。
- 源表环比行、备注、透视表都可能错。能从单元格重算的，以重算为准，并记进质量问题。
- 百分比在数据里用小数；界面再格式化。

公式、对账和拒绝清单见 [caliber.md](caliber.md)。

## 证据三层

每条原因只标一层，禁止把猜测写成事实。

| 层 | 能写 | 不能写 |
| --- | --- | --- |
| 数据证实 | 单元格直接算出来的变化、对账、结构拆解 | “所以是因为小红书 / 发券 / 决策变长” |
| 平台机制 | 万相台无界已核验的场景和报表维度，只用来选切面 | 用机制句顶替本周数字 |
| 待验证 | 源表猜测、内容场带店、券档、新老客、归因窗口 | 写进结论当事实 |

源表备注默认 `待验证`。若备注与单元格冲突（例如把占比变化写成消耗上涨），以单元格为 `数据证实`，把备注标成源表错误。

## 分析顺序

1. **总览**：本周消耗、推广 GMV、ROI、客单、CPC、CVR、展现、点击。同时报环比和正常周。
2. **验算**：`ROI = 推广GMV / 消耗`；`ROI ≈ CVR × 客单 / CPC`。对不上先查口径，不先讲故事。
3. **基数**：对照周展现是否异常放大。异常则漏斗环比不作提效证据。
4. **客单**：场景切换解释多少、场景内下降解释多少。用“若本周订单仍按对照周各场景客单计，客单应是多少”。
5. **五条通道**：关键词、人群、货品全站、店铺直达、超级短视频。谁加量、谁漏量、ROI 和客单一起看。
6. **关键词**：分类消耗 / GMV / ROI；高耗词里零成交和低于用户确认 ROI 阈值的项。小样本高 ROI 不作为扩量依据。
7. **人群**：智能 / 类目 / 品牌 / 竞品的消耗、占比、GMV 分开看。命名人群包对账人群推广。
8. **货品**：写清覆盖范围。不能默认货品线覆盖所有通道，以实际字段定义为准。
9. **月进度**：时间进度 vs 消耗 / 推广 GMV / ROI / 费比。推剩余日消耗上限。

禁止结论：`环比 ROI 涨了 = 全面提效`。

## 动作

每条必须有：做什么、负责人角色、观察窗口、通过条件、停手 / 回滚。先停浪费，再小步加有效通道。不把预算一次性切到单一场景。

## 交付

交付形式按当前任务选择 Markdown 或离线 HTML；HTML 契约仅在选择该形式时适用。版式、禁区和验收见 [report.md](report.md)。

不要写万相台产品介绍（“统一经营系统，不是单一广告位”一类）。读者已经在用这个工具。

正文和文件名只留业务名和日期。复制到桌面时用 ASCII 文件名，例如 `tmall-weekly-review-YYYY-MM-DD.html`。

## 每周提示词

WorkBuddy / 对话里只贴变量。模板见 [weekly-prompt.md](weekly-prompt.md)。
