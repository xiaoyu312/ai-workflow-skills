# HTML 报告契约

## 生成

HTML 只能由脚本 + 快照生成。禁止直接改 `report.html` 里的数字、判断或动作。

本公开包不附原业务生成器；使用经过审查的独立生成器，或由助手根据确认快照生成。

## 文件约束

- 单文件，CSS / JS / 数据全部内嵌
- 禁止 CDN、远程字体、远程图、fetch、在线接口
- 字体只用系统栈：Optima / Avenir Next / PingFang SC / Segoe UI / Microsoft YaHei
- 不写 token、sheet 内部 ID、MCP URL、账号密钥

## 必须有的交互

- 对照切换：异常周 vs 正常周；总览表和场景图一起变
- 关键词过滤：全部 / 零成交 / 低于目标 / 达到目标（目标由本次任务给定）
- 动作勾选，可用 localStorage；键名不要带内部 ID
- 章节锚点导航

## 必须有的图

柱状图，不要用三个点的折线冒充趋势。

1. 三周消耗 vs 推广 GMV
2. 分场景 GMV 增减（正负柱）
3. 关键词分类消耗：对照 vs 本周
4. 月完成率 vs 时间进度
5. 可选：货品线消耗结构条

图上要有刻度、单位、图例。金额可用“万”。

## 版式

- 封面深色（夜柜台玫瑰黑），浅色数据区
- 标题就是本周判断，不要空泛“周报”
- 封面药签只放消耗 / GMV / ROI / 客单，不要四块一样的 KPI 卡片
- 不要万相台产品介绍
- 不要外链字体、紫渐变、玻璃拟态、左侧彩条、01/02/03 章节眉

## 验收

- 桌面约 1440 和手机约 390：无内容级横向溢出
- 首屏能读完判断和四个数
- 对照按钮会改表头、涨跌和建议读法
- 给 Windows 同事：桌面 ASCII 文件名的 HTML，必要时再出 PDF
