一个以产品事实为输入、按渠道交付文案的通用 AI Skill。适合产品与运营人员、内容创作者，以及需要统一事实口径的文案协作。

## 先看交付示例

[合成产品](examples/synthetic-product.md)为虚构的三格收纳盒：18 × 12 × 5 cm、ABS 材质、不作食品容器。示例文案“桌面小物，各归一格”保留这些限制，不添加销量、优惠或防尘效果。它是说明用样稿，不是实测转化结果。

**最短入口：**让能读取 Markdown 的助手先读本目录的 [SKILL.md](SKILL.md)，再提交案例或自己的授权输入。完整目录与安装条件见下文。

本页提供三语介绍；操作指令、模板和部分示例仍以中文为主。可在请求中指定输出语言，但未验证跨宿主调用或日文生成效果。

## 能做什么

- 为命名、标题、短句、商品页、包装和口播选择适合的交付形式。
- 区分可写事实、表达选择和无依据的主张。
- 完成新写、最小范围修改或诊断，并保留必要限制与来源对应。
- 用原创空表整理简报和交付；用纯合成示例理解证据边界。

本公开版保留通用用途与自写任务路由，重新编写独立工作流和模板。它不包含原私有版本的课程知识库、逐课映射或课程材料，也不保证完整复现原课程体系或生成效果。

## 使用

将整个 `brand-copywriting` 文件夹放入支持 `SKILL.md` 的宿主技能目录，或让助手直接阅读 [SKILL.md](SKILL.md)。宿主安装方式可能不同；本包不安装依赖、不联网，也不自动发布文案。

示例请求：

> 使用 brand-copywriting。根据我提供的规格写一段商品简介，保留限制条件；对没有依据的销量、效果和优惠不要补写。先给推荐稿，再给一个语气不同的备选。
