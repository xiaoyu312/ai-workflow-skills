## 能做什么

- 为命名、标题、短句、商品页、包装和口播选择适合的交付形式。
- 区分可写事实、表达选择和无依据的主张。
- 完成新写、最小范围修改或诊断，并保留必要限制与来源对应。
- 用原创空表整理简报和交付；用纯合成示例理解证据边界。

## 使用

将整个 `brand-copywriting` 文件夹放入支持 `SKILL.md` 的宿主技能目录，或让助手直接阅读 [SKILL.md](SKILL.md)。宿主安装方式可能不同；本包不安装依赖、不联网，也不自动发布文案。

示例请求：

> 使用 brand-copywriting。根据我提供的规格写一段商品简介，保留限制条件；对没有依据的销量、效果和优惠不要补写。先给推荐稿，再给一个语气不同的备选。
