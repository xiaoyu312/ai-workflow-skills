# 品牌与产品文案

把用户提供的产品资料转成指定渠道可用的文案，并让每个实质性主张能追溯到资料。支持新写、定向修改和诊断；如果用户只要一句成稿，就交付一句，不强加整套报告。

这是独立通用工作流。它不依赖课程知识库，也不代表任何课程作者、平台或品牌。

## 先确定交付

从请求中识别用途与已有决定，保留用户明确指定的定位、口气和有效片段。

| 交付类型 | 本轮需要解决的问题 | 输出中的实用附注 |
| --- | --- | --- |
| 产品名或系列名 | 如何区分产品并让人读懂、念出 | 含义、读法、适用范围；可检索性或商标状态未查就不声称可注册 |
| 标题、短句或广告语 | 读者看完应记住或采取什么 | 推荐稿及各备选真正不同的表达目的 |
| 商品详情页、包装文字 | 哪些信息能帮助读者判断是否适合 | 分区文案、规格与适用限制，不能让氛围表达遮住必要信息 |
| 口播、直播或短视频文案 | 谁在说、说给谁、结束后做什么 | 可读出的正文及必要画面/证据提示；需要逐镜头拍摄表时另行展开 |
| 诊断或定向修改 | 用户指出的问题发生在哪一段 | 问题、最小修改及理由；不要自动重写其余部分 |

混合任务可共用一份事实表，但渠道稿应各自满足长度、语气和行动目标。

## 建立事实表

先使用已有资料；缺少会改变结论的事实才追问。可用 [文案简报](assets/copy-brief.md) 收集输入，不要求用户重复填写已经说明的字段。

区分三类输入：

- **可写事实**：用户或已查资料明确提供的规格、机制、用途与限制，给每项一个简短来源编号。
- **表达选择**：语气、叙事角度、顺序和节奏，可直接设计，不伪装成市场结论。
- **待确认主张**：优惠、库存、时效、效果、销量、排名、认证、引语和比较优势，缺证据就不写成既定事实。

用户提供的资料也可能互相矛盾。先指出会影响文案的冲突；暂用范围更窄、可核对的表述，不选对销售最有利的数字。不要自动读取客户名单、订单或私有工作文件来补齐简报。

## 写作与修改

1. 用一句工作说明写清“面向谁、在哪种场景、希望读者完成什么判断或动作”。它是本次编辑选择，不是对市场规模或消费者心理的研究结论。
2. 从有来源的事实中选择本次最相关的信息。没有比较资料时写清自身特征，不虚构相对竞品的优势。
3. 直接写适合目标渠道的完整稿。具体动作、规格和使用情境优先于空泛形容词；必要限制放在读者做决定前能看到的位置。
4. 对事实性句子回查来源。允许情绪性表达，但不能让它暗示未经证实的功能、健康结果或保证收益。
5. 用户要多个方案时，以读者任务、信息顺序或语气上的差别区分版本；用户只要求润色时控制改动范围。

引用评价时保留原意并确认使用权限；没有真实评价就使用清楚标明的演示文字，不能包装成用户证言。短句也不能省略会改变理解的适用条件。

## 交付与验证

按用户需要选择 [交付单](assets/delivery-sheet.md) 的字段。通常交付成稿、必要的待确认项和简短编辑说明即可；涉及多个主张或渠道时附来源对应表。

交稿前检查：

- 读者无需知道内部项目术语就能理解产品和行动。
- 所有价格、数字、承诺、认证、比较及引语都能对应来源；缺失项已删去或标成未采用。
- 文案与商品规格、活动条件、页面承接相符；文字长度和口播时长等限制有实际依据，估计值明确标注。
- 不为“吸引力”添加虚假紧迫、权威背书、竞品贬损或不实效果。
- 诊断稿保留了用户要求不变的内容，多个版本的差别可以说明。

若用户要验证方案，提出可执行的对照：只改变一个明确因素，记录渠道、受众、时间和观察指标。不把相关性当因果，也不编造实验结果。

演示见 [完全虚构的产品案例](examples/synthetic-product.md)。示例是格式和证据边界的说明，不是已完成的市场测试。
