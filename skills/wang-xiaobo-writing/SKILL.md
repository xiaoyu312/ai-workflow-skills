# 中文写作轻改

本公开版保留原项目中独立设计的编辑约束、用户反馈形成的轻改流程与原创合成样例。它不包含书籍、章节映射或依据书中故事归纳的文风技巧；保留 `wang-xiaobo-writing` 标识仅为兼容。范围和归属见 [LICENSE-STATUS.md](LICENSE-STATUS.md) 与 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

取舍顺序：事实与当前任务要求 → 用户原稿和明确反馈中的口气 → 以下可覆盖的默认偏好。默认清楚、平实，幽默可有可无；用户本次明确要求更锋利、更文学或更长时，再调整。

## 可覆盖的改稿默认值

这些是工具的编辑默认值，不是对任何用户性格的推断：

- 发动态时偏短、直接，像自己说话。用户说“再短一点”时，优先删上一稿额外加的包袱、解释和升华，保留必要事实、使用信息和行动入口；不只是把句子切碎。
- 幽默自然一点，不刻意抖机灵。可以整篇没有笑点，不自动加俏皮收尾、自嘲或“有哲理”的反转。
- 以用户亲自写的原稿为口气基准。保留已经合适的开场、常用词、直白表达和表情；只改拖沓、歧义或衔接不顺的地方，不必为了证明改过而整段重写。
- 后续明确反馈优先于初次风格标签。用户说“这句不像我”“别这么写”，据此修稿即可，不要求先解释完整的自我认识。

这些是默认偏好，用户本次的具体要求可以覆盖。不要把 AI 自己写出的句子、用户未逐句反对的上一稿，或单次素材中的态度，擅自存成用户长期口气。

## 接到任务

- **改稿**：先识别必须保留的事实、立场、数字、专名、引语和原稿里有个性的句子。已有原稿就先做必要的小改；需要大幅重排时由实际问题或用户要求决定，不为文风改变论点或补造情节。缩写仍须保留“几套／部分／这次”等适用范围；不能把不同功能合并成同一个能力，也不能把“会说明依据”缩成对结论可靠性的保证。
- **新写**：从已有材料找到一个值得细看的问题。材料不足时，仍可写明确标出的假设或观点短文；缺失事实会改变结论时，只问一个关键问题。
- **诊断**：指出具体句子哪里没有内容、哪里推不出来、哪里显得用力，给局部改法。用户只要诊断时，不擅自整篇改写。

从对话继承主题、读者、平台、长度、立场和语气。已有材料足够就写，不索要人格画像或要求用户先“认识自己”。平台不明时用普通中文短文；用户指定的结构和用途优先。

需要原创合成样例时，读取 [before-after.md](references/before-after.md)。不要把示例当成用户经历。

## 去 AI 味的修改顺序

先改内容和推理，再改措辞。不要把替换几个高频词当作完成。

| 发现的问题 | 实际修改 |
| --- | --- |
| 把主题名换掉，整段还能用于别的文章 | 找到这个主题独有的事实、冲突或细节；没有就删 |
| 一串名词：赋能、抓手、底层逻辑、价值闭环 | 写出行为、对象和变化；必要的行业术语保留并说清 |
| “不是 A，而是 B”没有真的排除 A | 直接说 B；确有区别时保留并证明 |
| 每段都对仗、排比、反问、反转 | 让句子承担不同功能；保留必要的一处，不按配额造句 |
| 小标题已经讲完全文，正文只重复 | 补具体过程和推理，或缩短篇幅 |
| 结尾忽然出现时代、人性、未来、真正的自由 | 检查前文是否支持这个尺度；通常缩回眼前的问题 |
| 为了像真人而加错字、碎句、网络梗、虚构经历 | 撤掉表演，保留自然语序和真实材料 |
| 为了模仿某位作家而反复用名句、口头禅、骂人 | 回到观察与论证；另写自己的句子 |

这些是诊断线索，不是禁词表。排比、长句、总结、比喻和“我认为”都能用，关键是它们此刻有没有作用。示例中的措辞和篇章顺序也不是模板。

## 适配自媒体

- **短帖／即刻／朋友圈**：让一个发现讲完整。段落按意思分，不把每句话拆成一行。默认不加互动诱饵。
- **公众号／长随笔**：围绕同一个问题逐渐展开，允许场景、插话和回返。小标题帮助导航即可，不强凑“三个底层逻辑”。
- **小红书**：标题和首段明确读者会看到什么，例子要能被看懂。保留真实经验的边界，不制造“所有人都错了”的姿态。
- **口播**：改成听一遍能接上的语言，减少括号套括号、难辨的指代和连续概念。用户给时长时按实际朗读调整，不保证字数等于时长。
- **商业内容**：产品事实、功效、价格和行动信息保持准确，幽默不能替代证明。用户要求正式、严肃或安慰性内容时，服从用途，减少反讽。

## 交付前的读稿

静默检查，发现问题就改，不默认输出评分表：

1. 这还是用户在说话吗？有没有替换掉原稿顺口的表达，或加上用户没有的机灵、世故和自嘲？
2. 用户想说的话还在吗？数字、条件和因果强度有没有被悄悄改掉？
3. 生动的细节从哪里来？有没有把假设装成事实，把第一人称装成亲历？
4. 读者能说出文章在讨论的具体问题吗？每个关键结论能接回前文吗？
5. 读出声时哪里绕口、重复或刻意？各段是否又变成同一种节奏？
6. 新加的笑点是否有必要？需要认真之处是否得到了认真对待？要求缩短时，是否真正删了多余内容？
7. 是否偷渡了作者的生平、现成故事、标志性句子或未经核实的名人引语？

只输出用户要求的成品。请求多个版本时才给多个；请求解释时才附修改说明。写作任务不自动发帖或发送消息。

本公开版不冒充任何作家或声称获得作家授权；不声称模型经过特定作品训练。所谓“减少 AI 味”以具体、清楚、自然和可信来检查，不承诺检测器结果。
