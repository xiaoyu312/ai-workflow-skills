# 中文写作轻改

[English](README.en.md)

一个保留个人口气和事实边界的中文写作 Skill。它适合修改动态、自媒体草稿、随笔与口播，也能按请求提供局部诊断。

状态：**公开源码实验版**。此精简版本的功能与验证范围见下文。

## 本公开版的范围

- 保留原有的“先保留事实与用户表达，再做必要的小改”流程。
- 保留数字、适用范围、条件和因果强度；不补造亲历、对话或否定性细节。
- 提供平台适配、去套话检查及原创合成改稿样例。
- 默认不添加笑点、升华或多个版本；正式说明可直接保持正式。

原项目标识为 `wang-xiaobo-writing`，为兼容继续使用。原项目曾研究王小波《沉默的大多数》；本公开版移除了书籍样本映射、章节内容锚点和依赖这些样本的技巧归纳。它不提供原版的完整文风蒸馏内容，不宣称得到作家或权利人认可。

独立保留依据与授权范围见 [LICENSE-STATUS.md](LICENSE-STATUS.md) 和 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 使用

本包不需要脚本、网络、API 密钥、源书或额外依赖。它提供指令，不附带模型。

1. 将整个目录保存在支持读取 Markdown 指令的 AI 助手环境中。
2. 明确要求助手先读取 `SKILL.md`，再处理你的草稿。其相对引用与 `references/` 一起保留。
3. 如果宿主支持以名称调用已安装 Skill，可使用 `$wang-xiaobo-writing`。具体安装位置与发现机制由宿主决定；本包不自动安装。

示例请求：

> 先读取这个目录的 SKILL.md。帮我轻改下面的中文草稿，保留事实和我的口气，简短自然，只给正文。

Skill 不会自动发帖、发送消息或修改外部系统。

## 合成演示

以下内容为本次独立构造，不是用户真实业务或匿名化快照。

输入：

> 我今天试了一个提醒工具。只试了 3 次，其中 1 次提醒晚了 2 分钟。先继续试试。

可接受的轻改：

> 今天试了个提醒工具，试了 3 次，其中 1 次晚了 2 分钟。先继续试试。

不能改成“提醒稳定可靠”“已经节省大量时间”，也不能把单次试用扩写为总体结论。完整、固定的合成输入与验收点在 [examples/synthetic-cases.json](examples/synthetic-cases.json)；更多原创教学例子在 [references/before-after.md](references/before-after.md)。
