# Qianchuan Script Creator

提供された商品事実と撮影条件から、撮影用の短尺動画脚本を組み立てます。ライブ配信や商品ページへの誘導、指定箇所の修正、レビュー、一変数だけを変えた案、データに基づく検証仮説を扱います。

独立して整えた汎用の公開版です。作者のタスク分岐と商品事実・誘導先の確認を残し、新しい入力テンプレート、納品表、合成例を用意しました。非公開の講座知識ベースは含めず、元の方法や成果との同等性も主張しません。Douyin、Qianchuan、元講座の制作者とは提携しておらず、公認版でもありません。

## まずは 15 秒の脚本を見る

[合成ケース](examples/synthetic-cases.md)は、指定された卓上・スタンド・スマートフォンなどで撮る 15 秒の動画脚本を計画し、冒頭のショットだけを変更した対照案を作ります。確認済みの商品事実と未確認のキャンペーン条件を区別します。脚本や検証仮説は、プラットフォーム審査の通過や広告成果の証明ではありません。

**最短の入口：** アシスタントに [SKILL.md](SKILL.md) を先に読ませ、商品事実、視聴者、誘導先、尺、撮影条件を渡してください。

## 導入と使い方

Markdown の Skill に対応する利用環境にフォルダー全体を置き、その利用環境の手順で有効にします。アシスタントに `SKILL.md` を直接読ませても構いません。操作指示とテンプレートは中国語です。出力言語は指定できますが、今回の README 翻訳は日本語生成品質や利用環境への導入を検証したものではありません。

依頼例：

> qianchuan-script-creator を使い、私が渡す事実から 15 秒の商品動画の脚本を作成してください。使えるのは卓上と商品だけです。未確認のキャンペーンを足さず、冒頭のショットだけを変えた別案を一つ出してください。

効果分析を依頼する場合は、指標の定義と観測期間も提供してください。アカウントの秘密情報や顧客単位の記録は含めません。
