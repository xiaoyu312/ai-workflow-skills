# 经营看板设计系统

这是从用户自写界面中提取的通用设计约束。实现时以 [CSS tokens](tokens/colors_and_type.css) 为当前包内依据，不依赖原项目或私有预览。

## 使用流程

1. 明确阅读任务、屏幕宽度和数据状态，不凭空编造业务值。
2. 先读取 tokens，优先使用语义别名，不重复创建近似颜色。
3. 依内容层级安排标题、指标、解释和表格；数字对齐，窄屏允许表格局部滚动。
4. 状态同时用文字与颜色，缺失、待核、失败与真实零值分别表达。
5. 保留键盘焦点、缩放、对比度及减少动画设置；未实际验证的视口明确标为未验。

## 颜色基础

`tokens/colors_and_type.css` 的无前缀源变量已同步到本模板值：

- `--forest`（`#173d2d`）：固定侧栏与最高层级品牌深色。
- `--green`（`#214d3b`）：经营主强调色、选中态、主要进度与操作链接。
- `--leaf`（`#3d7958`）：轻量链接与可交互的次级强调色。
- `--canvas`（`#f5f6f2`）：当前页面底色；`--surface`（`#fff`）：卡片、表格与工作区表面。
- `--ink`（`#202c25`）：正文与金额；`--muted`（`#637169`）：说明、时间与辅助标签；`--line`（`#dfe5de`）：当前分隔线与边界；`--soft`（`#f5f7f2`）：当前低对比 hover/浅底。
- `--bad`（`#ac3f36`）、`--warn`（`#906322`）、`--good`（`#2c7050`）：错误、待核和已对账语义。错误、警告和成功必须保留文字说明，不能只依靠颜色。

原始基线仅为迁移记录，集中在 `--original-canvas #f4f6f4`、`--original-line #e2e8e3`、`--original-soft #f4f7f4` 和 `--original-font-ui`，不被任何 semantic token 或 UI kit 使用。使用语义别名（如 `--fg-1`、`--surface-primary`、`--border-subtle`、`--state-warning`）时始终指向当前值，不在新组件里再造旧绿色或旧灰阶。


## 字体与信息节奏

- 当前字体栈是 `"Avenir Next", "PingFang SC", "Microsoft YaHei", sans-serif`，由随包 tokens 的 `--font-ui` 提供；中文优先保证系统可读性。
- 原始设计使用：全局使用 `font-family: var(--font-ui)`，组件 SVG 文本使用 `font-family: inherit`，按钮/输入/选择器使用 `font: inherit`；没有其他字体家族。
- 当前默认正文为后置全局规则生效的 `14px / 1.55`（早期 `body` 的 `13px` 仅保留为 `--original-size-body` 对照）；基础 `h1` 为 `29px / 1.3 / 650`，基础 `h2` 为 `16px / 1.45 / 600`，基础 `h3` 为 `14px / 600`。
- 当前 `.section-head h2` 在桌面默认值为 `18px`，窄屏 `max-width: 760px` 下为 `17px`；`.demand-page .section-head h2` 保留其上下文值，桌面为 `18px`、窄屏为 `16px`。页面标题在响应式规则下为 `25px` 或 `24px`，因此不要把基础 `h1` 当成所有视口的最终值。
- 当前说明文字最终以 `12px` 为主，`.caption`、`.panel-foot` 等的后置行高为 `1.7`；金额、数量、时间、比例和版本号使用 `font-variant-numeric: tabular-nums`，确保表格与 KPI 对齐。
- 中文标题使用句式标题，不使用全大写英文装饰。标签、来源和口径说明短而具体，保留“待核”“沿用”“历史快照”等数据状态词。


## 布局与组件约定

- 页面可使用固定深绿色侧栏（源宽度 `202px`）与右侧工作区；内容区最大宽度为 `1550px`，桌面内边距通常为 `32px`。当前页面底色、分隔线和浅底分别使用 `#f5f6f2`、`#dfe5de`、`#f5f7f2`。
- 卡片边界以 `1px` 线和留白表达，主面板圆角 `12px`；控制件通常使用 `7px` 或更小圆角。阴影只用于抽屉等确有层级的浮层，普通面板不依赖重阴影。
- KPI、渠道卡片、趋势图、成本结构和动作列表保持信息优先的网格密度。数据表支持横向滚动，不强行压缩列宽。
- 交互控件沿用 `0.16s` 的背景/文字/边框过渡；卡片 hover 用浅底与边界变化表达。保留 `prefers-reduced-motion: reduce` 分支。
- 焦点态沿用 `3px solid #669e7b`、`3px` offset；所有按钮、链接、输入、选择器和 `summary` 都必须保留可见 `:focus-visible`。


## 数据和资产边界

不在设计系统复制业务快照、客户记录、内部来源标识或真实品牌图像。示例见 [合成预览](examples/index.html)，仅由固定种子的生成器构造。需要品牌资产时由使用者另行取得合法授权，不由本包提供。

## 验收

检查语义 token 引用、数字层级、信息阅读顺序、错误状态文本、焦点及响应式；静态源检查不等于浏览器视觉验收。
