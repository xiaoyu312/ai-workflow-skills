# 業務ダッシュボードのデザイン

中国語の業務ダッシュボード向けに、意味に応じた色、文字組み、レイアウト、データ状態、アクセシビリティの規約を整理する再利用可能なワークフローと CSS トークン集です。非公開の業務入力やメディアは含みません。

状態：**実験的な公開ソース版**。

## まずは独立した例を見る

[HTML の例](examples/index.html)と[合成データ](examples/demo.json)で、指標、表、状態表示の構成を確認できます。新しく作ったデータとシステムフォントだけを使い、実業務データには接続しません。今回ブラウザーで表示確認はしておらず、この例をもってレスポンシブ表示やアクセシビリティの検証済みとは扱いません。

**最短の入口：** フォルダーを丸ごと保ち、Markdown を読めるアシスタントに [SKILL.md](SKILL.md) を読ませて、例や許諾済みの要件を渡してください。

## 導入と使い方

利用環境が指定する Skill ディレクトリに、`operations-dashboard-design` の名前でフォルダー全体をコピーします。あるいは作業前に `SKILL.md` を直接読ませます。インストーラーはなく、利用環境固有の呼び出しやモデルの挙動は未検証です。

既存の呼び出し例：`Use $operations-dashboard-design with the synthetic examples and clearly mark missing facts.`

操作指示、テンプレート、一部の例は主に中国語です。この README の日本語化は、デザイン規約や UI 自体の日本語化を意味しません。日本語生成の品質も未検証です。

API キーや環境変数は不要で、使わない `.env.example` は同梱していません。プラットフォーム操作には利用環境側の許可済み機能が必要です。有料ジョブの投入、素材アップロード、業務記録の編集を自動で行いません。

## 提供範囲と制約

非公開の業務ダッシュボードを読み込んでいた元のラッパーは除外しています。`examples/index.html` は合成行とシステムフォントだけを使う独立した例です。データコネクターや OpenDesign ビューアーは含みません。

公開準備時には CSS 参照テストの通過が記録されています。ブラウザー描画、画面幅に応じた見た目、支援技術の挙動は未検証です。

## 合成例と確認コマンド

固定シードの例には「模拟数据 DEMO」と明示し、実データを匿名化したものは使用していません。Python 3 の標準ライブラリのみを使います。

```sh
python3 -B scripts/generate_demo.py
python3 -B -m unittest discover -s tests -p "test_*.py"
```

検査対象はファイル構造、参照、明示した例の制約です。モデル品質、現在のプラットフォーム機能、業務効果、生成メディアは検証しません。ホスト型サービスではなく、今回の文書整理でもパッケージのテストやブラウザー操作は実行していません。
