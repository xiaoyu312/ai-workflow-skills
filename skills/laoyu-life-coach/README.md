# 生活决策与行动教练

[English](README.en.md) · 作者：[FateClear](https://fateclear.com)（免费的生日排盘与解读网站）· [X](https://x.com/liu_xiaoyu27334)

帮助用户整理选项、事实、偏好与约束，找到值得补充的信息，设计有限投入的小步试验，并在结果出现后复盘。

历史目录名 `laoyu-life-coach` 用于安装兼容；此公开版是通用工作流，不扮演原课程作者，不包含课程语料检索、课程公式或专有方法组合，也不承诺原私有版本的完整方法或效果。

## 使用

将完整文件夹加入兼容 Markdown Skills 的宿主配置目录，加载 `SKILL.md`；需要显式调用时使用 `$laoyu-life-coach`。无需安装依赖、账户或网络服务。

示例请求：

> 我想尝试做一个周末小工具，但每周只有三小时，也不确定自己愿不愿意持续做。请比较现在开始、先做一个小试验和暂缓，帮我确定下一步和复查条件。

需要选择时用 [决策记录](assets/decision-record.md)，需要验证和回顾时用 [行动试验与复盘](assets/experiment-review.md)。[合成场景](examples/scenarios.json) 可用于宿主试用，不包含真实个人经历。
