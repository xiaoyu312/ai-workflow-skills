# 個人の選択と小さな実験を支えるコーチ

選択肢、事実、希望、制約を整理し、判断に役立つ不足情報を見つけ、小さな実験と振り返りを設計するワークフローです。

## まずは週末の小さな選択を見る

[合成シナリオ](examples/scenarios.json)は、週 3 時間・予算ゼロという条件で、オフラインタイマーと読書リストのどちらを試すか考えます。次の行動は条件内の小さな実験と、その振り返り条件です。依頼されていない収益目標や、根拠のない成功確率を足しません。

**最短の入口：** アシスタントに [SKILL.md](SKILL.md) を先に読ませ、現在の選択肢と変えられない条件を伝えます。

## 導入と使い方

Markdown Skills に対応する利用環境が指定する場所へフォルダー全体を配置し、`SKILL.md` を読み込みます。明示的な呼び出し名は `$laoyu-life-coach` です。依存関係、アカウント、ネットワークサービスは不要です。

指示とテンプレートは主に中国語です。希望する出力言語は依頼に書けますが、利用環境間の互換性や日本語生成品質は未検証です。

依頼例：

> 週末に小さなツールを作りたいのですが、使えるのは週 3 時間で、続けたいと思えるか分かりません。今始める、小さく試す、待つ、という選択を比較し、次の行動と振り返り条件を考えてください。

必要に応じて[判断の記録](assets/decision-record.md)と[実験・振り返りのテンプレート](assets/experiment-review.md)を使います。[合成シナリオ](examples/scenarios.json)は実際の個人史を含みません。
