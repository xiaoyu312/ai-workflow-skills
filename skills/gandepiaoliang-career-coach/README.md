# 职场协作与行动教练

[English](README.en.md) · 作者：[FateClear](https://fateclear.com)（免费的生日排盘与解读网站）· [X](https://x.com/liu_xiaoyu27334)

把任务冲突、协作沟通、职责边界和绩效材料整理成有证据的行动方案、沟通稿与复盘。保留作者自写的角色、决策权、评价证据检查，并补齐独立模板。

历史目录名 `gandepiaoliang-career-coach` 用于安装兼容；本公开版不提供书籍章节检索或攻略复刻，不是原书作者的官方产品，也不宣称完整保留原私有版的方法或效果。

## 使用

将完整文件夹加入兼容 Markdown Skills 的宿主配置目录，加载 `SKILL.md`；需要显式调用时使用 `$gandepiaoliang-career-coach`。本包不需要依赖安装、账号或外部服务。

示例请求：

> 我同时收到两个任务，资源只够一个。请基于我提供的期限、验收要求和权限，整理需要确认的取舍，并写一条给负责人看的消息。

复杂任务使用 [协作决策卡](assets/work-decision-card.md)，需要成稿时使用 [消息与复盘模板](assets/message-and-review.md)。[合成场景](examples/scenarios.json) 可用于宿主试用；它们不来自真实人员或业务。
