# 職場の連携と行動を整理するコーチ

競合するタスク、調整の問題、曖昧な責任、成果の根拠を整理し、具体的な行動、連絡文案、振り返りにつなげます。作者の役割・権限・証拠の確認手順を残し、独立したテンプレートを加えたパッケージです。

旧フォルダー名 `gandepiaoliang-career-coach` は導入の互換性のために保持しています。書籍の章構成や行動攻略集を再現するものではなく、原著者との公式な関係もありません。非公開版との完全な同等性は主張しません。

## まずはリソース調整の例を見る

[合成シナリオ](examples/scenarios.json)では、二つのタスクがそれぞれ半日のデザイン作業を必要としますが、確保できる時間は合計で半日だけです。調整担当者には優先順位を決める権限がありません。期限、受け入れ条件、選択の影響を整理し、決裁者に判断を求める文案を作ります。延期が承認されたことにしてはいけません。

**最短の入口：** フォルダーを保ち、アシスタントに [SKILL.md](SKILL.md) を読ませ、合成例か利用を許可された自分の状況を渡してください。

## 導入と使い方

Markdown Skills に対応する利用環境の指定場所へフォルダー全体を置き、`SKILL.md` を読み込みます。明示的な呼び出し名は `$gandepiaoliang-career-coach` です。依存関係、アカウント、外部サービスは不要です。

指示とテンプレートは主に中国語です。出力言語を依頼に書けますが、日本語生成品質や利用環境間の互換性を検証したものではありません。

依頼例：

> 二つのタスクが同じ限られたリソースを必要としています。私が示す期限、受け入れ条件、決定権をもとに取捨選択を整理し、責任者に判断を求める連絡文を作ってください。

複雑な場合は[仕事の判断カード](assets/work-decision-card.md)、提出時には[連絡と振り返りのテンプレート](assets/message-and-review.md)を使えます。[合成シナリオ](examples/scenarios.json)には実在の人物や業務記録を含みません。
