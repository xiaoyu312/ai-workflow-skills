## 導入と使い方

必要な `skills/<name>/` フォルダー全体を、利用環境が対応する Skill ディレクトリへコピーするか、アシスタントにその中の `SKILL.md` を読むよう依頼します。導入先と呼び出し方は利用環境の説明に従ってください。各 README に合成入力と、用意されている場合は確認コマンドを載せています。

このリポジトリのために API キーを作る必要はありません。コネクターは含まず、内容の公開や有料サービスの呼び出しを自動では行いません。実際のタスクの入力とツールの権限は利用者が用意します。

## 検証の範囲

ソース公開の準備段階には、ローカル構造、リンク、合成ケースの確認が記録されています。動画ディレクションは 13 件、週次レビュー、構成応用、デザインは各 4 件のテストが通過し、推敲パッケージは厳密なファイル一覧、14 個のリンク、2 個の合成ケースを確認しています。モデル品質、実際のプラットフォーム、業務効果、ブラウザーの見た目は未検証です。静的確認だけで、すべてのモデルが手順を正しく実行できるとは言えません。

後から加えた 6 パッケージでも独立した合成タスクを確認しています。範囲と未検証事項は各 README を参照してください。非公開版の手法や成果を完全に保持したとは主張しません。

今回の三言語文書整理では、これらの機能テストを再実行していません。推敲パッケージの静的検査はファイル一覧を固定し、パッケージ内のリンクだけを許可します。そのため日本語紹介はリポジトリの `docs/ja/` に置き、この索引から案内しています。パッケージ内は中英切り替えのみとし、作者の外部リンクはリポジトリ側にまとめています。検査のソースは変更していません。

すべての例は独立した合成データです。`python3 -B scripts/generate_all_examples.py` で公開例を再生成できます。このコマンドは業務ファイルを読まず、ネットワークにもアクセスしません。
